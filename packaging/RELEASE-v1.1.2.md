阅研是一款本机论文阅读器，支持原文 PDF 与中文译稿并排阅读、Zotero 文献库和 GPT 伴读。v1.1.2 修正了 Windows 便携包的启动路径。

- Windows 11 x64 下载 `PaperDesk-Windows-x64-v1.1.2.zip`。完整解压后双击 **Start Paper Desk.bat**。如提示缺少运行库，请安装 [Microsoft 官方 Visual C++ x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。
- macOS 14+（Apple 芯片）下载 `PaperDesk-macOS-arm64-v1.1.2.zip`。完整解压后双击 **启动阅研.command**。

两个安装包均从空文献库开始，并内置 Codex CLI 0.169.1。可用模型取决于登录账号。下载后可用 `SHA256SUMS.txt` 核对文件。

应用源码采用 AGPL-3.0 许可。依赖项的来源和对应源码见包内的 `SOURCES.md`。
