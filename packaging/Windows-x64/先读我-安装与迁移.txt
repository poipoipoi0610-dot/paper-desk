阅研 · Paper Desk 可移植版 1.1.1（2026-11-19）

适用电脑：Windows 11，64 位 Intel / AMD 电脑；此包不适用于 Windows ARM

一、第一次打开
1. 完整解压 ZIP，把整个 PaperDesk 文件夹放在 Documents、桌面或你有写入权限的位置。
   Windows 请勿放在 Program Files / Windows 目录；不要直接在压缩包中运行。
2. 双击 Start Paper Desk.bat。保留打开的终端 / 命令窗口，浏览器会自动打开。
   无需管理员权限，无需额外安装 Python、Node.js、WSL 或 Codex。
3. 首次打开为空文献库。上传 PDF、输入论文链接，或连接新电脑上的 Zotero 来导入论文。
4. 退出时，在启动窗口按 Ctrl+C 并等待停止。关闭网页本身不会停止服务。
   默认网址 http://127.0.0.1:8766；另一个版本占用时会选择其他本机端口，以启动窗口显示的网址为准。

二、ChatGPT 伴读
点击网页右上角账号按钮，按页面提示登录。已保存的原稿和译稿可离线阅读，新的翻译 / 框架 / 问答需要联网及可用账号用量。
包内没有账号凭据、API Key 或登录令牌；换电脑后按新电脑的登录状态使用。
这是 Codex 模型伴读，不迁移 ChatGPT 网页对话或自定义 GPT 配置。

三、Zotero
安装包不绑定任何 Zotero 账号，不携带旧账号的文献、分类、附件或关联缓存。
1. 在同一电脑安装并打开 Zotero，登录你要使用的新账号，等待该账号的文献库同步完成。
2. 在 Zotero「设置 → 高级」开启「允许此计算机上的其他应用程序与 Zotero 通信」。
3. 把要读的 PDF 下载到本机，在阅研点击「文献库 → Zotero 文献库 → 刷新」。
阅研读取的是本机 Zotero 当前打开的文献库，无需在阅研输入 Zotero 密码或云端 API Key。
以后在 Zotero 切换账号 / 数据库后，先完成同步，再回到阅读器刷新并重新选择论文。
阅读器已经导入的原文和译稿保存在自己的 data 中；若希望不同账号完全分开，可分别解压一份安装包。

四、换电脑、换系统与升级
1. 先停止两边的阅读器。
2. 同系统同芯片：复制整个 PaperDesk 文件夹，到了新电脑双击启动。
3. macOS 与 Windows 之间：在目标电脑解压对应系统包，把旧文件夹里的 data 整个复制过去。
   目标文件夹已有文献时，先把 data 重命名备份，再复制旧 data；不要混合覆盖两个不同文献库。
4. 升级到新包也用同样的方法迁移 data，原来的包和数据先保留。
5. 原文、中文页、合并译稿、论文框架和阅读对话均在 data 中；主题、缩放和滚动位置是浏览器设置，不随包迁移。
   不要复制其他系统的 runtime 或 .venv，不要将账号目录混入安装包。

五、检查问题
双击 Check Paper Desk.bat，查看同目录 diagnostics.txt；不调用模型，不发送论文，不导出账号凭据。
如果提示缺少 codex_bridge 或其他模块，请重新完整解压，不要只复制 server.py。
如果提示不能写入 data，请把整个文件夹移到 Documents 或桌面。
两版仅监听本机 127.0.0.1；这是单机阅读器。

文件清单及校验：files-sha256.txt
运行依赖来源、固定版本和上游校验：runtime-sources.json / requirements-*.lock.txt
