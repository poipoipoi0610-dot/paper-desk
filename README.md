# 阅研 · Paper Desk

本机三栏论文阅读器：原文 PDF、保留页面布局的中文 PDF 译稿、论文框架 / GPT 伴读。

## 下载和启动

到 GitHub 的 **Releases** 页面下载对应的 ZIP，完整解压到可写入的文件夹。

| 系统 | 下载包 | 启动方式 |
| --- | --- | --- |
| Windows 11 x64（Intel / AMD） | `PaperDesk-Windows-x64-v1.1.2.zip` | 双击 **Start Paper Desk.bat** |
| macOS 14+（Apple 芯片） | `PaperDesk-macOS-arm64-v1.1.2.zip` | 双击 **启动阅研.command** |

两个便携包均内置 Python、PDF 依赖和 Codex CLI。Windows 如果提示缺少 Visual C++ 运行库，请安装 [Microsoft 官方 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)。启动后会打开本机浏览器，退出时在启动窗口按 Ctrl+C。详细步骤见包内《先读我-安装与迁移》。

## 从源码运行

需要 Python 3.11+。在 macOS 上运行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python launch.py
```

在 Windows 上运行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launch.py
```

生成和伴读使用本机 Codex CLI。macOS 上会优先使用已安装的 ChatGPT 桌面应用自带的 Codex，也可以通过 `PAPER_DESK_CODEX` 指定可执行文件。点击阅研右上角账号按钮查看连接；未登录时使用官方 ChatGPT 登录页。可用模型取决于 CLI 版本及账号。

项目采用 [AGPL-3.0](LICENSE)。第三方组件及其源码位置见 [SOURCES.md](SOURCES.md)。

## 使用

1. 导入文字型 PDF，或输入 arXiv 编号 / 链接、DOI、直接 PDF 链接、包含公开 PDF 的论文网页。
2. 自动生成带原文页码的研究动机、方法、实验、结果和局限；之后逐页翻译并保存。
3. 页面会自动更新，已译页面可以立即阅读。暂停、失败或重启后点击“继续生成”，已有译文会复用。
4. 点击左侧原文段落，中间中文 PDF 自动定位并高亮对应段落；点击中文段落也可返回原文。无需切换模式，独立滚动时点击定位仍有效。所选段落也可引用到右侧 GPT 对话，回答页码可点击返回原文。
5. “滚动已锁定”默认开启，任一 PDF 栏滚动都会按页面位置带动另一栏。点击开关可独立滚动。
6. 全文完成后下载合并后的中文 PDF。页面使用 PDF 矢量显示，文字和线条随缩放保持清晰；下载后的 PDF 含可提取的译文文本。

7. 顶部仅保留紧凑标题与阅读工具；点击“论文信息”展开完整标题、原文链接和中文 PDF 下载。
8. 点击图上的“点击放大”，在大图查看器中使用滚轮、＋／−缩放并拖动查看，双击放大／还原，Esc 关闭。“放大本页”可查看整页；少数未识别的图片也可以从整页放大查看。矢量图保留矢量，照片保留原文件像素，无法恢复原稿中不存在的细节。

## 界面主题

界面采用黑白灰底色和蓝色操作提示。右上角切换「深色 / 浅色」，首次使用默认深色，浏览器会记住选择。主题覆盖阅读器、GPT 伴读、文献库和弹窗。

阅读工具栏的「纸张：柔和 / 原色」单独控制 PDF 亮度；深色默认柔和，浅色默认原色，手动选择后会独立保存。该设置只影响阅读页，放大查看图片和下载的 PDF 保持原色。

## Zotero 文献库

1. 保持 Zotero 10 或更新版本运行，在「设置 → 高级」开启「允许此计算机上的其他应用程序与 Zotero 通信」。无需云端 API Key 或额外插件。
2. 在阅研点击「文献库 → Zotero 文献库」。支持个人文库、本机可用的群组文库、分类（含子分类）、标题 / 作者 / 年份 / 标签搜索，以及「仅有 PDF」筛选。
3. 点击「打开阅读」读取所选 PDF；多个 PDF 附件可以切换选择。默认只解析原文，在阅读页点击「开始生成」，或事先勾选「打开后生成中文译稿与论文框架」来启动 AI。
4. 文献库窗口打开且页面可见时，每 30 秒检查更新；也可点击「刷新」。列表有变更才重新读取，所有连接均通过本机接口。
5. 文件按内容去重，同一份 PDF 复用译稿、框架和聊天记录。PDF 内容发生变化会作为新版本导入，旧阅读记录保留。Zotero 条目关联使用实例、文库、条目和附件标识，避免混淆不同数据库。
6. PDF 需要已下载到本机。只有网页条目、尚未下载、链接文件丢失时会显示相应提示。已导入的论文即使 Zotero 关闭，仍能在「本机已导入」阅读。

当前为 Zotero 到阅研的读取与按需导入，不会将译稿、笔记写回 Zotero。浏览列表不调用 AI；只有主动生成或提问才发送论文文字。分类 / 标签在 Zotero 中管理。

## 数据与账号

- 单用户、本机版，仅监听 `127.0.0.1`。没有外网部署，不适合直接开放端口给他人使用。
- 上传文件、译稿、框架和聊天存于 `data/`，关闭后保留。浏览器只保存阅读位置、主题与滚动偏好。
- 搬家前先停止阅读器；同系统复制整个可移植文件夹，跨系统使用目标系统的安装包并迁移 `data/`。替换目标数据前先重命名备份，避免合并覆盖。启动器会检查完整性和写入权限；多个数据目录同时运行时使用不同的本机端口。
- 论文文本和对话通过本机 Codex app-server 发送给 OpenAI，计入相应账号用量。凭据由 Codex 管理，不复制到本项目，不提供原始凭据接口。
- 这是通过你的 ChatGPT 登录使用 Codex 模型的阅读助手，**不导入 ChatGPT 网页历史、自定义 GPT 的知识文件或配置**。应用自身的阅读对话保存在本机。
- 同源校验、CSRF 令牌、Host 检查保护本地操作。下载器阻止内网和本机地址，逐次验证重定向，连接固定到已验证 IP。论文文本作为不可信资料处理。
- 模型调用为无工具文本任务，禁用本进程的 shell、应用、浏览器、MCP 与插件；不修改用户的 Codex 配置。新任务为临时会话。

## 当前边界

- 最大 64 MB、300 页。扫描 PDF 需要先 OCR；密码 PDF 需要先解锁。不能绕过网站登录或付费墙。
- 译稿在原文文本区域内重排，保留原图、图形和独立公式。复杂图中文字、公式混排、密集表格并非专业出版级翻译；请对照原文。过长译文若不能在最小比例内放下，会保留原文并记录提示，点击对应段落可在中文 PDF 上方浮层阅读完整中文，不会静默丢字。
- 文本提取顺序受 PDF 结构影响，复杂多栏和矢量图标签可能需要人工检查。
- 极长论文的框架使用逐页摘录，并在页面显示说明；聊天使用逐页提要与相关原文。页码是 PDF 的物理页码。
- Codex app-server 接口可能随版本变化。应用使用本机 CLI 生成的协议做过实际验证，升级 CLI 后应复测。

```sh
.venv/bin/python -m unittest discover -s tests -v
node --test tests/sync.test.mjs
```

测试覆盖 PDF 提取、中文内容保留、页码导出、URL 标准化 / 私网阻断、段落定位与缩放坐标、Zotero 附件归属校验、数据库切换、分页和缺失附件提示。真实账号端到端验证单独进行，不在单元测试中消耗模型用量。
